Live train status

Three colours. One clear next stop.

The live page is built around the question that matters while you are on the train: what is next, and am I still on the right route?

  • Next booking stop — the blue Next chip and map label always belong to the next stop where you can get off, never an intermediate halt.
  • Green stays green — journey stations keep their green background after departure, so you can still see your route at a glance.
  • Fold anything — tap a booking stop to open its intermediate halts, and tap again to close. The train marker snaps to the booking stop when folded.
  • Pick any run — use Today, Tomorrow, Yesterday, Day before yesterday, or open the calendar to track an older or future run.

Journey planning

Connections that actually make sense.

A search is not just a list of trains. AM Train Planner expands every run that touches your window, prunes impossible changes, and keeps routes that get you there.

  • Direct trains and up to five changes, with a minimum 10-minute change.
  • Optional walking transfers between nearby stations, shown on the map as a dotted line.
  • Weekday chips for every result, so you can see which dates the same route actually runs.
  • Cancel a long search instantly; results already on screen stay put.

How it works

Search once. Follow the run.

The timetable lives on your phone. Live data is fetched only when you need it.

Plan the route

Enter From and To, add a via station if you have one, and choose the next seven days or a date window. The app finds direct trains and connections.

Open the train

Tap any train in a result to see every stop, scheduled and actual times, platform numbers, and the part of the route that belongs to your journey.

Track it live

Refresh for the latest position, or turn on Fast update for GPS-assisted tracking. Fold intermediate halts, switch the date, and read the next booking stop.

Under the hood

Small app. Serious timetable.

No Gradle, no web view, no account. A compact Java app builds a SQLite timetable on the device and keeps the live layer separate from the offline plan.

Questions

Good to know

Everything you need before your first search.

Does AM Train Planner work offline?

Yes for journey planning, station/train search, the route map and the offline timetable. Live running status, live seat availability, timetable updates and app update checks need an internet connection.

Where does the timetable come from?

The app ships a compact base schedule, builds a SQLite database on the phone, and can apply patches from the railway timetable service. It does not ship a ready-made 18 MB database. The bundled schedule is a snapshot and can lag behind the railway's latest timetable; use the refresh button to apply available patches.

Is the live tracking official?

No. The live page uses an unofficial live-status endpoint. It can show a timetable estimate when the service has no recent position. AM Train Planner is not affiliated with Indian Railways, IRCTC, Where Is My Train or ConfirmTkt.

Why does Fast update need location?

Fast update uses the phone's GPS only inside the segment between the current and next station reported by the live service. It is optional, asks for permission when you turn it on, and runs only while the live page is open. The reported station always wins, so an inaccurate GPS fix cannot move the marker backwards.

Which Android versions are supported?

Android 7.0 (API 24) and newer. The current release targets API 36.

How do I update the timetable?

Tap the refresh button on the timetable data row. The app checks the railway timetable service and applies a newer patch. You can also drop a timetable.db, .sqlite, patch.zip or jingli file into the app's own inbox folder, or set an optional host link.

How do I update the app?

AM Train Planner checks GitHub Releases every time it opens. If a newer APK exists, a dialog offers Download & Install or Update later. You can also tap the download icon in the app header to check manually. Android asks once for permission to install unknown apps; the updater verifies the package and signing key before opening the installer. Automatic checks stay silent when the app is current.

Is AM Train Planner open source?

Yes. The complete source code is public at github.com/adiraimaji/AMTrainPlanner. Anyone can view and use it, build their own APK, and send issues or pull requests.

Does it collect my data?

No account is created, there are no ads and no trackers. Your searches stay on the phone. Internet is used only for live status, seat availability, timetable updates and app update checks.

How do I report a bug?

Open an issue at github.com/adiraimaji/AMTrainPlanner/issues with the train number, date, and what you expected to see. A screenshot of the live page helps a lot.
